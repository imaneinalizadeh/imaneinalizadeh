# Experiment 2: AI-Generated Content — Attempt 3 (NYT Titles, Final)

## Overview

This is Attempt 3 of 3 — the final and successful experiment in the AI-Generated Content taxonomy extension. It closes the remaining domain gap identified in Attempt 2 by using short NYT-style article titles generated by five different LLMs, whose length and linguistic style match Fakeddit Reddit post titles almost exactly.

The result is AI-Generated F1 = **0.90** (Precision 0.92, Recall 0.86), meeting and exceeding the target threshold of F1 > 0.85.

---

## Motivation

Attempt 2 demonstrated that reducing the length gap between training data and Fakeddit test titles improved F1 from 0.11 to 0.71. However, Reuters-style text still carried a formal journalistic register that differed from casual Reddit post title style. The hypothesis for Attempt 3: **if training data matches Fakeddit titles in both length and style, recall should reach the target threshold.**

The `gsingh1-py/train` dataset provides NYT article titles used as prompts for five LLMs. The resulting generated titles are short, punchy, and headline-style — the same format as Reddit post titles.

---

## Setup

### Base Model

Loaded from `hierarchical_v3_best.pt` (Attempt 2 output, AI-Generated F1 0.71).

### Freezing Strategy

| Component | Status | Reason |
|-----------|--------|--------|
| BERT encoder | PARTIALLY UNFROZEN | lr=1e-5 — allows fine adaptation to new domain without catastrophic forgetting |
| Group 0 fine head | FROZEN | Handles True Content — unrelated |
| Group 1 fine head | FROZEN | Handles Structural Deception — unrelated |
| Group 2 fine head | RETRAINED (4 outputs) | lr=2e-5 — higher rate for classification heads |
| Coarse head | RETRAINED | lr=2e-5 — updated to refine routing with new data |

**Key architectural change from Attempts 1 and 2:** BERT is no longer fully frozen. Differential learning rates are applied — BERT at lr=1e-5 and classification heads at lr=2e-5. This allows the shared encoder to adapt its representations toward the new domain while the faster-learning heads drive the classification signal.

```
[BERT Encoder]     ←── PARTIALLY UNFROZEN (lr=1e-5)
       |
  [Coarse Head]    ←── RETRAINED (lr=2e-5)
       |
  ┌────┴──────────────┐
  │                   │
Group 1 Head      Group 2 Head   ←── RETRAINED (lr=2e-5)
(FROZEN)          (4 outputs: Satire, Imposter, Manipulated, AI-Generated)
```

### External Dataset: gsingh1-py/train

| Property | Value |
|----------|-------|
| Dataset | gsingh1-py/train |
| Content | NYT article titles used as prompts; generated by 5 LLMs |
| LLM sources | GPT-4o, Llama-8B, Mistral-7B, Qwen-2-72B, Gemma-2-9B |
| Text fields used | `prompt` field + first sentence from each model column |
| Length filter | 15–120 characters |
| Unique samples after dedup | ~25,000 |
| Average length | ~50–70 characters |
| Fakeddit title average | ~55 characters |

**Why five LLM sources:** Using outputs from multiple models prevents the detector from keying on a single model's stylistic fingerprint. A detector trained only on GPT-4o output may fail to detect Llama-generated content. Mixing five sources produces a more general AI-Generated detector.

### Domain Alignment — The Key Insight

```

   society has prompted extensive debate among scholars, policymakers..."
  → ~300 words | formal academic prose | F1 0.11

Attempt 2 (artnitolog Reuters):

Attempt 3 (gsingh1-py NYT titles):

```

### Weighted Cross-Entropy Loss

Class imbalance is addressed with weighted loss — a key improvement over Attempts 1 and 2.

| Class | Weight | Reason |
|-------|--------|--------|
| AI-Generated (6) | 2× | New class being introduced — reinforce learning signal |
| Imposter Content (3) | 3× | Chronically hard category (55% error rate in error analysis) |
| Manipulated Content (5) | 2.5× | Second hardest category |
| Satire/Parody (1) | 2× | Small class, underrepresented in training |

### Augmentation Applied

| Transform | Count | Purpose |
|-----------|-------|---------|
| Drop last word | ~6,000 | Simulate shorter Reddit-style truncation |
| Lowercase | ~6,000 | Match casual Reddit capitalisation |
| Uppercase | ~6,000 | Handle ALL CAPS clickbait style |
| Minor word reorder | ~6,000 | Add surface variation |

### Training Hyperparameters

| Parameter | Value |
|-----------|-------|
| BERT learning rate | 1e-5 |
| Head learning rate | 2e-5 |
| Batch size | 32 |
| Epochs | 4 |
| Optimiser | AdamW with OneCycleLR scheduler |
| Warmup | 10% of steps |

## Discussion

The jump from F1 0.71 to F1 0.90 confirms the final piece of the domain mismatch hypothesis: it is not just length that matters, but **linguistic register**. Reuters text and NYT titles are both roughly headline-length, but the stylistic character of NYT titles — short, punchy, single-idea, often without articles — matches Fakeddit Reddit post titles at a surface level that Reuters does not.

The partial unfreezing of BERT (lr=1e-5) contributed to the improvement. Fully frozen BERT in Attempts 1 and 2 meant the shared encoder could not adapt at all — it had to rely entirely on the classification head to learn the new category. Allowing gentle BERT adaptation gave the model flexibility to shift its internal representations toward the new domain without forgetting what it had already learned.

The three-attempt process demonstrates a transferable principle for emerging category detection:

1. **Attempt 1:** Establish a failure baseline. Reveals the domain mismatch problem.
2. **Attempt 2:** Partial fix. Confirms the hypothesis and quantifies the gap.
3. **Attempt 3:** Full fix. Matches domain precisely and achieves target performance.

## Key Takeaway

The domain mismatch problem is fully resolved by matching the format, length, and linguistic register of the external training data to the target distribution. Using five LLM sources on NYT-style short titles produced an AI-Generated detector that achieves F1 0.90 — compared to F1 0.11 when trained on long essays. **The label attached to training data is necessary but not sufficient — the surface format of the text is equally critical for emerging category detection.**
